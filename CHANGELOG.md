# Changelog

Release PRs maintain versioned entries above the initial product overview below.
The maintainer reviews release notes before merging each release PR.

## Initial product overview

- Native Linux image viewing with lazy folder navigation, temporary file lists,
  and streaming ZIP, 7z and RAR access.
- JPEG, PNG, WebP, BMP and DIB; configurable scaling, embedded ICC conversion,
  EXIF orientation, view rotation and physical-pixel actual size.
- Fullscreen overlays, configurable viewer shortcuts, metadata, lazy thumbnails
  and temporary image comparison.
- Memory-only caches and archive access, with no application-owned activity
  history, persistent thumbnails, archive extraction or normal file logs.
- Native Arch Linux x86_64 and Fedora 44 x86_64 packages using system libraries.

See the [user guide](docs/user-guide.md) for controls and limitations and the
[platform matrix](packaging/README.md) for dependency exclusions.
